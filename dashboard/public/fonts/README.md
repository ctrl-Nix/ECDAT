# Self-hosted fonts

This folder contains the Inter and JetBrains Mono Latin WOFF2 web fonts used by the dashboard. Both typefaces are distributed under SIL Open Font License 1.1. The downloaded Google Fonts WOFF2 resources are variable font files; the weight-named copies satisfy the expected asset inventory, while `@font-face` declares the supported weight range. Keep both upstream notices (`OFL.txt` for Inter and `JetBrainsMono-OFL.txt` for JetBrains Mono) with the binaries.

Files: `Inter-Regular.woff2`, `Inter-Medium.woff2`, `Inter-SemiBold.woff2`, `Inter-Bold.woff2`; `JetBrainsMono-Regular.woff2`, `JetBrainsMono-Medium.woff2`, `JetBrainsMono-SemiBold.woff2`.
