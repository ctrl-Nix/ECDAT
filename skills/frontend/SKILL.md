# Frontend Skill

Rules:
- React 18 + Vite.
- Use Recharts for all charts.
- Use TailwindCSS.
- Dark theme color: #0B0E14.
- IBM Plex Mono for code/data.
- Space Grotesk for headings.
- IBM Plex Sans for body.
- Load all data from the API; no mock data.
- Use Axios for HTTP.
- Show loading states everywhere.
- Include error handling.
- Poll scan status every 3 seconds.

Components:
- StatCards
- FindingsTable
- ChartsPanel (Recharts BarChart + PieChart)
- RiskBadge
- ConfidenceStamp

Pages:
- ScanList (/)
- ScanDetail (/scans/:id)
